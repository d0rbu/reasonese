# Glossary

| Term | Meaning |
|---|---|
| Condition | One rendered representation or social-framing treatment. |
| Directive | A condition instantiated with a response code inside a trial. |
| Counterbalance | A target-assignment or prompt-order reversal used to cancel simple nuisance effects. |
| Design ID | Digest of all experiment inputs that affect rendered trials. |
| Trial ID | Digest of one rendered trial's identity fields. |
| Decisive outcome | A response that exactly equals one requested nonce code after outer-whitespace trimming. |
| Invalid outcome | Any other response; retained but excluded from Bradley-Terry wins and losses. |
| Neuralese-like | Incident-inspired compressed observable text; not a claim about hidden model computation. |
| Log strength | A centered Bradley-Terry parameter; score differences determine pairwise win probability. |
| Synthetic response | Output sampled by the local simulator from configured strengths, never empirical evidence. |
| Endpoint provenance | Exact provider, model/version, date, decoding settings, and request metadata for a collection run. |
